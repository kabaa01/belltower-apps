# BellTower Tools
Static web apps (no server). Hosted with GitHub Pages.
- `/` landing page, `terms.html`, `privacy.html`
- `vukiq-mapato/` reconciliation tool, `vukiq-kazi/` creator tool, `vukiq/` profile cards
Before going live: set the payment number in `CONFIG` in each app's `index.html`, add your public licence key as `pub` in `vukiq-mapato/index.html`, and fill the `[add]` placeholders in `terms.html` and `privacy.html`. Never commit the private licence key or the admin folder.
